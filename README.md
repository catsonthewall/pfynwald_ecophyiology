# Pfynwald remote sensing exercise

It is a learning subset for fixed dates, selected for manageable size and shared observation coverage, not for a desired treatment effect. All source identifiers, original timestamp strings, and quality flags are retained. The license is CC BY 4.0; credit the original authors, DOI, and date filtering when using the data.

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python verify_inputs.py
